# The-Spark

The Spark is a completely functional social media page I've built using Claude Code. It uses 'Supabase' for a free API, and Github pages to stay active. It's available at the link https://dubepaige.github.io/The-Spark/.

The Spark is also available as an app for Iphone users, currently going through testing. It's available through Testflight at the link https://testflight.apple.com/join/xFh6zYrA.
